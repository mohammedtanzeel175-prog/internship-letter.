# Internship Letter — Cinematic Static Website

## Files
- `index.html` — page structure
- `style.css` — visual design and animations
- `script.js` — cinematic sequence, particles, audio and CTA

## Change the CTA
Open `script.js` and change:

const CTA_URL = "https://example.com";

to the destination you want.

## Run locally
Open `index.html` in a modern browser.

## Deploy
Upload all three files to a public GitHub repository and enable GitHub Pages.
